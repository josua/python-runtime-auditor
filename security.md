# Security and privacy

The auditor reads filesystem metadata and venv configuration files. Discovered
executables are not launched. Its own reports are written to the selected output
directory, and report assets are copied there. Existing reports in the same run
directory can be regenerated by the analysis/report commands.

Reports can disclose usernames, application names and local filesystem paths.
Review them before sharing. They are excluded by `.gitignore`.

Imported JSON is treated as data. HTML delimiters are escaped when embedding
JSON, the UI uses text nodes, and the report's policy blocks network connections.
No claim is made that a metadata audit establishes whether an executable is safe
to run or whether an installation can be deleted.

For a security issue, use GitHub's private vulnerability reporting if it is
enabled on the repository. Otherwise report a minimal redacted issue without
credentials, personal paths or a working exploit against someone else's machine.
